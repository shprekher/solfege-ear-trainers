# Готовое задание для OpenCode

Открой этот проект и прочитай `AGENTS.md`, `README.md`, `DEPLOY.md`.

Нужно опубликовать русскоязычные тренажёры музыкального слуха как один статический сайт, сохранив их функциональность:

- Главная: `index.html` (кнопки для выбора упражнения).
- `/half-step.html` — два звука, второй на полтона выше или ниже первого.
- `/count-notes.html` — подсчёт количества одновременно звучащих нот: 2, 3, 4.
- `/shifted-voice.html` — после созвучия из 2/3 нот звучит одна смещённая на ±1 полутон нота; ответ: нижний/средний/верхний и вверх/вниз.

## План работы

1. Проверить целостность HTML и локально запустить сайт. Не менять игровую логику/тембры/паузы/статистику/прошлые исправления.
2. Проверить в браузере навигацию, звук после пользовательского нажатия, корректный/неверный ответ и разбор, повторы, переключение тембра, адаптивность на 432×934 и 393×852. Чётко указать, какие проверки удалось сделать.
3. При наличии авторизации создать публичный GitHub-репозиторий `solfege-ear-trainers` (если такого нет; не затереть существующий), сделать commit и push в `main`. Если нет авторизации — попросить владельца пройти login.
4. Использовать Tuqo для публикации без VPN в России: создать сайт в аккаунте пользователя, подключить **Git CD -> GitHub -> repo -> main**, дождаться деплоя. Авторизация аккаунтов и предоставление разрешений только со стороны пользователя. Альтернатива при проблемах — Beget Free, см. `DEPLOY.md`.
5. Указать фактические ссылки на репозиторий, главную страницу и оба упражнения; проверить HTTP-ответы и работу браузера; если нет доступа/полномочий — честно указать, что именно не удалось выполнить и что требуется от владельца.

## Условия

- Без npm, серверного кода и сторонних CDN. `index.html` должен оставаться в корне.
- Вся функциональность должна работать в мобильном Safari и на современных десктопных браузерах. Если физически проверить Safari нельзя, не заявлять о таком тестировании.
- Не добавлять в репозиторий учётные данные и ключи.
- Уважать GPL-2.0 звуковых сэмплов TimGM6mb и сохранять атрибуцию.
- Не создавать фальшивые URL и не утверждать, что сайт доступен из России без проверки с российской сети.
