Семь самостоятельных интерактивных упражнений на русском языке для телефона и компьютера.

## Быстрый запуск

Запустите локальный сервер (для общей истории всех упражнений страницы должны открываться с одного адреса сайта):

```sh
python3 -m http.server 8000
```

Адрес: `http://localhost:8000/`. Никаких npm, Node.js, серверной базы данных или сборки не требуется. Каждое упражнение содержит встроенные MP3-сэмплы пианино и электропиано; синтезатор на Web Audio API остаётся резервным вариантом. История сохраняется в IndexedDB браузера. Сайт загружает только собственные статические файлы; статистика никуда не отправляется.

## Локальный прогресс

- Ссылка «Мой прогресс» на главной открывает общие показатели, регулярность, личные рекорды, последние 20 тренировок и детализацию по упражнению и режиму. Полная история доступна через экспорт.
- Текущий уровень — точность последних 30 ответов **в выбранном режиме**; до 30 ответов оценка предварительная. Число голосов, тембр, ключ, язык и тип интервала не смешиваются. График показывает скользящую точность на конец каждого активного дня (до 60 последних дней с ответами).
- Один ответ записывается при окончательной проверке. Повторы и незавершённый выбор голоса не учитываются. Тренировка начинается с первого ответа; сброс, перезагрузка и перерыв более 30 минут начинают новую. Пустые запуски не считаются тренировками. Дни учитываются по местной дате ответа; текущая серия сохраняется, если последнее занятие было вчера.
- «Сбросить» в упражнении очищает текущие счётчики, но не историю. Полное удаление истории — только на странице прогресса, с подтверждением. После удаления новые ответы записываются заново.
- JSON-импорт объединяет историю, пропускает идентичные ответы по идентификатору, проверяет весь файл и откатывается целиком при конфликте. Поддерживается до 20 МБ / 100 000 ответов за импорт. Неизвестные версии файла отклоняются без изменения данных.
- База `solfege-ear-trainers-progress`, версия 2: версия 1 создаёт записи ответов и индексы упражнения/времени, версия 2 добавляет индекс тренировки. Миграции только добавляют структуру, не удаляют ответы. Версия JSON-формата — 1, не привязана к версии кода. Не менять имя базы при выпуске обновлений. При добавлении полей/индексов повышать версию и сохранять старые данные; никогда не удалять базу в обработчике ошибки открытия.
- Запись асинхронна и не управляет игровыми таймерами. Если IndexedDB недоступна или заполнена, игра продолжает работать, а пользователь получает предупреждение о несохранении истории.
- История привязана к origin (протокол, домен, порт) и профилю браузера. `localhost`, `127.0.0.1` и публичный домен имеют разные истории. Для переноса используйте JSON. Очистка браузера, приватный режим и вытеснение данных браузером могут удалить историю; экспортируйте резервную копию. Старые тренировки до добавления истории восстановить невозможно.

Проверки без установки зависимостей: откройте `/tests/progress-tests.html`, `/tests/progress-integration.html` и `/tests/progress-page-tests.html` на локальном сервере. Они используют временные базы, не затрагивая историю пользователя. Интеграционные проверки воспроизводят звуки упражнений.

## Основные правила

### Музыкальные диктанты

Новый раздел доступен по ссылке «Диктанты» на главной. Личный бот принимает пересланные сообщения «текст → аудио», буквально сохраняет условия и выдаёт файл `.solfege`. Один импорт файла на сайте добавляет занятие с датой и необязательным описанием. Аудио и позиции остаются в браузере, исходный порядок и нумерация преподавателя не переименовываются. Есть поиск, страницы списка, отметки, перемотка, волна, ±3 с, A–B и скорость с сохранением высоты. Конец записи не переключает задание.

Сайт по-прежнему статический. Бот запускается **отдельным процессом** на компьютере/VPS с исходящим доступом к Telegram. Действующий токен создаётся владельцем через @BotFather и хранится только в приватном окружении бота, не в сайте. Аудиофайлы не размещаются в публичном репозитории. Подробные инструкции запуска, systemd, ограничения форматов, резервное копирование и тесты: **[DICTATIONS_SETUP.md](DICTATIONS_SETUP.md)**.

### Тренажёры

- Интерфейс на русском языке.
- Не менять игровой процесс, звук, таймеры, статистику, конфетти и адаптивную вёрстку без отдельного запроса.
- Браузер разрешает звук после действия пользователя: нажмите стартовую кнопку.
- Электронный и акустический режимы переключаются внутри каждого упражнения.
- Второе упражнение **не сообщает заранее число голосов**; «Средний» для двухголосного случая неверен. Второй сигнал — **одна изменённая нота**, а не новое созвучие.
- Повтор разбора ошибки не влияет на статистику и не должен отменять переход к следующему вопросу.

## Публикация

См. [DEPLOY.md](DEPLOY.md). Рекомендуемая схема: GitHub как репозиторий, Tuqo с российской инфраструктурой как публичный сайт. Адрес публикации выдаст хостинг после подключения аккаунта.

### Адреса сайта

- Исходники: https://github.com/shprekher/solfege-ear-trainers
- Главная: https://solfege-ear-trainers.tuqo.ru/
- «Выше или ниже?»: https://solfege-ear-trainers.tuqo.ru/half-step.html
- «Сколько нот?»: https://solfege-ear-trainers.tuqo.ru/count-notes.html
- «Какой голос изменился?»: https://solfege-ear-trainers.tuqo.ru/shifted-voice.html

Tuqo Git CD подключён к публичному HTTPS-адресу репозитория и ветке `main`; вебхук GitHub передаёт события `push`. Сборка и npm не нужны. Секрет вебхука хранится в настройках сервисов, не в репозитории.

По отдельному запросу владельца в первом упражнении добавлены показатели «Ответов» и «Рекорд», оформление строки статистики взято из второго упражнения. Алгоритм подсчёта результатов не менялся. Проверки и ограничения описаны в [TESTING.md](TESTING.md).
