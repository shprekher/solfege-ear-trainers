# Публикация сайта (GitHub -\> российский хостинг)

## Рекомендуемый путь: GitHub + Tuqo

GitHub хранит исходные файлы. Tuqo публикует готовый статический сайт на российской инфраструктуре, с HTTPS и поддоменом `*.tuqo.ru`. Tuqo заявляет бесплатный тариф и интеграцию Git CD для GitHub (актуальность и ограничения тарифа уточняйте в панели).

1. В OpenCode откройте **корень этой папки**. Прочитайте `AGENTS.md` и `OPENCODE_TASK.md`.

2. Убедитесь, что Git и GitHub CLI (`gh`) доступны, а вход в GitHub выполнен. При необходимости пользователь запускает `gh auth login` **самостоятельно**. Не передавать токены в сообщения.

3. Если репозитория ещё нет, рекомендуемый вариант (после проверки и согласия пользователя):

```
git init
git branch -M main
git add .
git commit -m "feat: add two solfege ear training exercises"
gh repo create solfege-ear-trainers --public --source=. --remote=origin --push
```

Если репозиторий уже существует, **не** выполнять `gh repo create` и **не** перезаписывать историю. Сначала проверить `git remote -v`, `git status` и запросить подтверждение при конфликте.

4. Войти в [панель Tuqo](https://app.tuqo.ru/) через браузер. Создать статический сайт (без `package.json` и без сборки).

5. В разделе **Git CD** подключить GitHub (OAuth), выбрать созданный репозиторий и ветку `main`, затем привязать. Если для подключения требуется действие владельца аккаунта — выполнить его вручную в браузере.

6. Дождаться фактического результата развёртывания в панели. Проверить публичные адреса:

   - `/` — стартовая страница;

   - `/half-step.html` — упражнение 0: второй звук выше или ниже первого;

   - `/count-notes.html` — упражнение 1: сколько нот звучит;

   - `/shifted-voice.html` — упражнение 2: какой голос изменился.

7. Проверить звук после нажатия «Начать» и доступность ссылки из российской сети/через российского провайдера. Географическую доступность **нельзя гарантировать** только по месту серверов.

8. Последующие `git push` в привязанную ветку должны запускать деплой через Git CD; фактический результат сверять в панели.

Официальная информация: [Tuqo Git CD](https://tuqo.ru/git/), [Tuqo бесплатный тариф](https://tuqo.ru/hosting-v-rossii/).

## Раздел диктантов и Telegram-бот

`dictations.html`, `dictation.html` и их CSS/JS публикуются тем же статическим Git CD. Проверяйте также `/dictations.html`. Бот **не запускается на статическом хостинге**: это отдельный Python-процесс на компьютере/VPS, который выдаёт файлы `.solfege` для явного импорта на сайте. Установка BotFather, разрешённые Telegram ID, приватный каталог данных и systemd описаны в [DICTATIONS_SETUP.md](DICTATIONS_SETUP.md).

Не размещайте токен, настоящие `.env`, SQLite или записи преподавателя в публичном каталоге/репозитории. `.gitignore` исключает такие файлы, но сам по себе не защищает локальный HTTP-сервер, если вручную положить приватные материалы в обслуживаемую папку. По умолчанию бот хранит их вне папки сайта.
